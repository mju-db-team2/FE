# SI Manager Web App

이 프로젝트는 SI 회사의 프로젝트 및 인력 관리를 위한 웹 애플리케이션의 프론트엔드 프로토타입입니다.
React, Vite, Tailwind CSS를 사용하여 개발되었습니다.

## 시작하기

### 필수 조건
- Node.js (v18 이상 권장)
- npm

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```
브라우저에서 `http://localhost:5173`으로 접속하여 확인합니다.

### 빌드

```bash
npm run build
```

## 프로젝트 구조

- `src/components`: 재사용 가능한 컴포넌트 (Layout 등)
- `src/pages`: 주요 페이지 (Dashboard, Projects, Employees, Evaluations)
- `src/App.jsx`: 라우팅 설정
- `tailwind.config.js`: Tailwind CSS 설정 (색상 테마 등)

## 주요 기능

1. **대시보드**: 전체 프로젝트 및 인력 현황 요약
2. **프로젝트 관리**: 프로젝트 목록 조회 및 상태 확인
3. **인력 관리**: 직원 목록 및 상세 정보 조회
4. **평가 관리**: PM, 동료, 고객 평가 내역 조회
